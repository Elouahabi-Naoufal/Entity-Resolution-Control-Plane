## About The Project

This repository is currently **empty**. It has no source code, no configuration and no commits
before the commit that adds this README.

The repository is reserved for a full-stack control plane for entity-resolution workflows, planned
as part of the fourth-year internship at Office des Changes. The intended scope is a Splink/DuckDB
matching engine, a human review queue and identity-governance features, exposed through a Flask API
and a React interface.

Because nothing has been implemented here yet, this README does not describe features, commands or
results that do not exist. The internship work that is available today lives in the related
repositories:

* [entity-resolution-OC](https://github.com/Elouahabi-Naoufal/entity-resolution-OC) — the working
  Splink + XGBoost control plane.
* [entity-resolution-internship-report](https://github.com/Elouahabi-Naoufal/entity-resolution-internship-report) —
  the LaTeX report describing the methodology and the platform.

## Getting Started

### Prerequisites

* Git
* The toolchain for the planned stack, installed when the implementation starts.

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Elouahabi-Naoufal/Entity-Resolution-Control-Plane.git
   cd Entity-Resolution-Control-Plane
   ```

2. There is nothing to install or start at this stage.
